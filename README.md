# 🍔 Bora Delivery

Aplicação web de delivery desenvolvida com foco em uma experiência moderna, intuitiva e responsiva para navegação por categorias, restaurantes e produtos.

## 🚀 Sobre o projeto

O **Bora Delivery** é uma aplicação front-end inspirada em plataformas de delivery, permitindo que o usuário explore categorias, visualize produtos e gerencie itens no carrinho.

O projeto foi desenvolvido como parte do meu portfólio, com foco na aplicação prática de conceitos de desenvolvimento Front-End, componentização, responsividade e experiência do usuário.

## ✨ Funcionalidades

* 🏠 Página inicial com seção Hero
* 🍕 Navegação por categorias
* 🏪 Listagem de restaurantes
* 🛒 Adição de produtos ao carrinho
* ➕ Controle de quantidade dos produtos
* ➖ Remoção/redução de quantidade
* 💰 Cálculo do total do carrinho
* 📱 Layout responsivo
* 🎨 Interface moderna e intuitiva
* 🧩 Componentização da aplicação

## 🛠️ Tecnologias utilizadas

* **React**
* **TypeScript**
* **Vite**
* **CSS**
* **React Router**
* **Git e GitHub**

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/caquitooliveira/bora-delivery.git
```

Entre na pasta:

```bash
cd bora-delivery
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
